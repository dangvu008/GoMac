# Feature in Development Template

Use when a feature is being developed, in beta, or not yet publicly available.

## Template

```markdown
Cảm ơn bạn đã quan tâm đến VKey!

## ⏳ [feature_status]

[feature_description]

[how_to_enable_if_beta]

Mong bạn tiếp tục theo dõi và ủng hộ! 🙏
```

## Feature Status Options

- Đang phát triển
- Chế độ Beta
- Test Private
- Sắp ra mắt

## Placeholders

- `[feature_status]` - Current status of the feature
- `[feature_description]` - Description of the feature and its current state
- `[how_to_enable_if_beta]` - Instructions to enable if in beta (optional)

## Example - Beta Feature

```markdown
Cảm ơn bạn đã quan tâm đến VKey!

## ⏳ Chế độ Beta

Tính năng **Auto-restore tiếng Anh** đang ở chế độ thử nghiệm.

**Cách bật:**
1. Click vào icon VKey trên menu bar
2. Chọn Cài đặt
3. Bật "Tự động khôi phục từ tiếng Anh"

Mong bạn tiếp tục theo dõi và ủng hộ! 🙏
```

## Example - Private Beta

```markdown
Cảm ơn bạn đã quan tâm đến VKey!

## ⏳ Test Private

Hiện tại phiên bản Linux đang ở chế độ **beta**, test private và chưa public. Chúng mình đang nỗ lực hoàn thiện để sớm gửi đến cộng đồng.

Mong bạn tiếp tục theo dõi và ủng hộ! 🙏
```
